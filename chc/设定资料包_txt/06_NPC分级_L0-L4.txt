# NPC人物设定_L0-L4分级
用途：告诉上下文规划器和人工整理者：哪些资料该放在哪一层，什么时候升级读取。

## L0 索引层
定义：身份、角色类型、所属势力、当前位置、短摘要、profileRef。用于快速知道“是谁”。
推荐位置：npc_registry / relation node
读取时机：任何NPC出场、场景挂载、战斗目标识别。

## L1 轻演绎层
定义：称呼、语气、动作锚、当前动机、可见信息。短对话和轻互动读到这里即可。
推荐位置：npc_profile_records.L1
读取时机：短对话、轻互动、临时任务、普通问询。

## L2 结构深层
定义：秘密、长期目标、关系、规则、弱点、反制入口、不能误写的边界。说服/威胁/欺骗/阵营影响需要读取。
推荐位置：npc_profile_records.L2
读取时机：说服/威胁/欺骗、关系变化、秘密试探、阵营影响。

## L3 全保真层
定义：完整角色来源、人物故事线素材、RAG长文、特殊私有规则。永久后果、高风险状态改变或全局后果裁决时读取。
推荐位置：npc_profile_records.L3
读取时机：永久后果、高风险状态改变、全局后果裁决、人物故事线素材、长RAG核对。

## L4 角色卡/世界包常驻锚
定义：跨聊天继承的世界尺度、世界枢纽、主角入口、全局反派和基础规则。L4不等于每轮塞进prompt，只表示资料应随角色包长期保留。
推荐位置：character scoped data / permanent world package
读取时机：角色包初始化、世界尺度、主角入口、全局反派和跨聊天继承。

## 本包角色分配建议

L4：
- 禁器网络/某人 [l4_forbidden_network]：跨洲反派压力、母器权限、符灰布点、铜雀台代理人行动的总锚点。；记录：目标库：organization_registry / npc_profile_records / special_item_registry；来源：chc/某人 与 RPG配置
- 碧水清研/李寻道家族线 [l4_bishui_family_line]：白手起家入口、水灵玉佩、清研异常和李飞轩旧事都从这里展开。；记录：目标库：主角入口模板 / npc_profile_records / item/special；来源：{{user}}主角卡、清研、李飞轩、RPG配置
- 灵霄方家线 [l4_lingxiao_family_line]：巫雅萍、方瑶光、方璇玑、方澜共同构成中洲核心压力；方澜视角时尤其应提升为L4。；记录：目标库：organization_registry / npc_profile_records / relationship_graph；来源：巫雅萍、方瑶光、方璇玑、方澜原始目录
- 八荒世界尺度 [l4_world_scale]：境界、法器、禁术、地图和奖励尺度是所有裁决的上限，不应塞进角色卡长文。；记录：world_lore_records; realm_registry; reference_texts

L3：
- 所有已有角色目录且有完整 profile 的核心NPC：清研、巫雅萍、方瑶光、方璇玑、方澜、独孤萱、婉悦、文丽、沈若棠、温青蘅、苏锦娘、李飞轩、胧、某人。
- L3 不代表每轮全读；只有高风险、永久变化、深度互动、状态切换、人物故事线推进或世界线后果时读取。

L2：
- 文岳、洛媚、恶童、碧水长老、云来楼代理人、任务堂执事等支线/线索/压力对象。
- 若连续互动、投入资源、结仇结盟、牵连禁器或成为反制入口，可晋升为L3。

L1：
- 任务堂执事、临时商贩、巡海弟子、黑市中介、药童、跑堂、船主、擂台对手等场景功能NPC。
- 必须有过期条件；没有后果就注销。

L0：
- 背景人群、无名弟子、围观者、一次性可感知对象。不编号，不写长期状态。

## 分层写法模板
L0：id/name/role/faction/currentLocation/summary/profileRef。
L1：称呼、语气、动作锚、当前动机、玩家可见信息、禁忌误写。
L2：隐藏事实、长期目标、关系、秘密、弱点、边界、可交互入口。
L3：完整来源、人物故事线素材、RAG tags、状态机、特殊私有规则。
L4：跨聊天世界锚、主角入口、全局反派、量尺、基础世界法则。
