【八荒 RAG 资料索引】

用途：把复杂、冗长、不要求稳定精确触发的设定放进RAG/资料库。角色卡和System负责硬规则；World Info负责短触发器；RAG负责补细节、语气、事件素材和原始设定出处。

一、三层分工

角色卡/System/Author's Note：
放必须常驻的硬控制。包括不掷骰、不替{{user}}行动、状态格式、事件生命周期、奖励入账、初始态/成品态分层、傀儡权限、战斗交换、RAG不得覆盖当前状态。

World Info/Lorebook：
放灵活触发器。每条只保留短概况、硬边界、RAG查询方向。触发后提示GM去RAG中找长设定，但即使RAG没触发，短概况也足够继续跑。

RAG/资料库：
放长文档。包括角色完整描述、对话示例、事件目录、重要事件、原始txt、世界观长设定、旧版本方案。RAG内容只提供素材，不自动成为当前事实。

二、不要放入RAG的内容

当前【状态】、主角属性、活跃事件、反派计时、库存、未鉴定物、奖励结算、已归档结果、硬禁令和安全边界。它们必须在角色卡、System、Author's Note或当前对话状态中维护。

四、RAG查询模板

NPC短场景：
`RAG查询：角色名 + 语气 + 动作锚 + 初始态`
例：`RAG查询：方瑶光 语气 动作锚 初始态 照雪刀君`

NPC深度互动：
`RAG查询：角色名 + 角色描述 + 对话示例 + 关系边界`
例：`RAG查询：苏锦娘 角色描述 对话示例 情报交易 边界`

固定触发事件：
`RAG查询：角色名 + 事件目录 + T事件关键词 + 初始态禁止`
例：`RAG查询：婉悦 事件目录 项圈事件 初始态 禁止成品态`

世界观细节：
`RAG查询：地点/势力名 + 世界书 + 原始设定 + 当前场景`
例：`RAG查询：蜃楼城 地下拍卖会 世界书 原始设定 禁器残件`

功法法器生成：
`RAG查询：地域 + 属性 + 功法/法器 + 代价 + 反制`
例：`RAG查询：碧水 水法 功法 法器 代价 反制`

世界回合与事件源：
`RAG查询：势力名/NPC名 + 世界回合 + 事件源 + 奖励池`
例：`RAG查询：云来楼 世界回合 拍卖会 奖励池 竞争者`

经典桥段事件牌：
`RAG查询：桥段名 + 事件牌 + 入口 + 竞争者 + 奖励池`
例：`RAG查询：宗门大比 事件牌 改签 下药 大比奖励`
例：`RAG查询：秘境探索 事件牌 传承殿 出口崩塌 杀人夺宝`

行为合理性/OOC判定：
`RAG查询：合理性判定 + 越权声明 + 境界压制 + 可行改写`
例：`RAG查询：炼气杀大乘 超纲行动 可行改写 长期事件`

目标导航/旁白导引：
`RAG查询：目标 + 地域/势力 + 功法/法器/升级 + 入口 + 代价风险`
例：`RAG查询：追踪灵丝 法器 云来楼 赤焰器坊 蜃楼黑市 代价风险`
例：`RAG查询：炼气十层 升级 闭关 任务堂 内门选拔 修行点`

角色/傀儡台账：
`RAG查询：角色名 + 身份 + 当前状态 + 关系边界 + 能力短标签`
例：`RAG查询：方瑶光 初始态 身份 关系边界 照雪刀意`
例：`RAG查询：傀儡台账 PUP 权限 控制源 稳定 暴露 反制`

关注度/临时对象注销：
`RAG查询：随机NPC/随机事件 + 关注度 + 晋升条件 + 注销条件`
例：`RAG查询：送错账单跑堂 TMP F1 F2 晋升 云来楼 错账线 注销`
例：`RAG查询：黑船船主 随机NPC 交易 后果 角色晋升 注销`

五、RAG吸收规则

每次检索只吸收1-3个锚点：
语气锚、动作锚、地点细节、事件线索、设定名、反制入口、物品外观。

不要整段搬运RAG。RAG检索到的长段落应压缩成：
`来源：文件/关键词；采用：锚点1、锚点2、锚点3；不采用：与当前状态冲突的内容。`

若RAG与当前状态冲突：
当前状态 > Author's Note > System/角色卡硬规则 > World Info短概况 > RAG长文。

若RAG里写的是后期成品态：
不能直接写成当前事实。把它登记为T固定触发事件、长期事件候选，或作为未来结算分支。

六、世界书触发器模板

触发词：角色名, 别称, 势力, 关键物
内容：
短概况：一句当前事实。
硬边界：一句禁止误写。
演绎锚：称呼/语气/动作。
RAG查询：推荐检索的文件或关键词。

示例：
触发词：方瑶光, 照雪刀君, 少宗主
内容：方瑶光初始是灵霄观少宗主、元婴巅峰刀修，正在追查邪修。硬边界：开局不是灵骸或亡者。演绎锚：称阁下；先听后答；手按刀柄不拔。RAG查询：方瑶光/角色描述.txt + 方瑶光/对话示例.txt + 方瑶光/事件目录.txt。

七、切分建议

RAG片段建议300-800汉字一段。每段开头写标签：
`#角色 #方瑶光 #语气 #初始态`
`#事件 #T01 #灵霄观 #固定触发`
`#世界观 #蜃楼城 #地下拍卖会`
`#法器 #碧水 #水法 #生成素材`

标签要包含角色名、势力、状态层、事件编号或玩法用途，方便检索命中。
