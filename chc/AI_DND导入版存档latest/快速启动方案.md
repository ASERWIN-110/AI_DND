# CHC AI_DND 快速启动方案

## 1. 启动 AI_DND

在项目根目录 `/Users/veritas/Documents/AI_DND` 双击：

```text
quick-start.command
```

或在终端运行：

```bash
cd /Users/veritas/Documents/AI_DND
./quick-start.command
```

启动成功后会显示：

```text
Chat:         http://127.0.0.1:8787/
Tool Manager: http://127.0.0.1:8787/tool-manager/
```

默认会打开 Tool Manager；如果没有自动打开，就手动访问：

```text
http://127.0.0.1:8787/
```

## 2. 导入 CHC 存档

导入文件必须选择 JSON bundle，不要选择 TXT。

可导入文件：

```text
chc/AI_DND导入版存档latest/八荒RPG_最终导入存档.bundle.json
```

兼容副本：

```text
chc/AI_DND导入版存档latest/八荒RPG_AI_DND_完整存档.bundle.json
```

在 Chat 页面右侧角色区点击导入，只填写角色卡 JSON 路径：

```text
chc/AI_DND导入版存档latest/八荒RPG_最终导入存档.bundle.json
```

sidecar 路径留空。这个 bundle 已经内含角色卡、initial setting、数据库、RAG、世界书短索引和参考文本。

## 3. 新建聊天

导入完成后，用 `八荒GM - AI_DND结构化存档` 新建聊天。

这个存档内含多个主角入口，新聊天正常会进入主角选择。选择后系统会把该主角绑定到当前聊天数据库；有固定 greeting 的入口会自动写入第一条玩家开场，没有 greeting 的入口不会固定初始处境。

- `李寻道`：有固定 greeting，初始处境是碧水宫外门。
- `方澜`：有固定 greeting，初始处境是灵霄观疑心线。
- `某人`：有固定 greeting，初始处境是禁器网络幕后。
- `视角未定`：没有 greeting，不固定开场，第一句自行声明身份和地点。
- `自定义角色`：没有 greeting，不固定开场，由 AI 按玩家声明和数据库生成。

## 4. 推荐第一句

李寻道：

```text
我以李寻道/清研之子的身份，从碧水宫外门开局，并启用逆命潮种金手指。
```

方澜：

```text
我以方澜的视角，从灵霄观疑心线开局，并启用破妄雷心气运。
```

自定义角色：

```text
我以自定义天命散修身份，从蜃楼城黑市开局，给2个带代价的成长型金手指。
```

## 5. 核对用文件

这个 TXT 只用于人工审阅，不用于导入：

```text
chc/AI_DND导入版存档latest/八荒RPG_最终设定存档.txt
```

如果手动改了 `chc/设定资料包_txt`，重新生成审阅 TXT：

```bash
npm run chc:merge-txt -- --force
```

如果改了生成脚本或数据库内容，重新生成可导入 JSON：

```bash
node scripts/build-chc-ai-dnd-bundle.mjs
```

然后再导入：

```text
chc/AI_DND导入版存档latest/八荒RPG_最终导入存档.bundle.json
```
