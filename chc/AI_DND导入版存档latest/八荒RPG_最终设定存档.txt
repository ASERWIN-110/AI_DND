# 世界观设定
用途：写入 world_lore_records / reference_texts / RAG。这里只保留世界事实、边界和玩法，不写角色卡长提示。

## 八荒地理格局 [lore_geography]
分类：geography
优先级：95
关键词：五洲、地理、地图
事实：八荒乃是古称，今实为五洲。上古时东方蜃楼与南方碧水之间本有陆桥相连，西方赤焰与北方归尘之间亦有地脉贯通——故旧称"八荒"。后沧海桑田，陆桥沉没，地脉断裂，四荒两两合并，又经独孤萱镇压九幽地眼后从裂隙中抬出一块新陆，遂成今日格局：

东洲（东荒+南荒旧地）：东海蜃楼城、碧水宫七十二岛。海雾弥天，珊瑚浮岛与沉船龙骨堆叠。蜃楼城是八荒最大自由港，其下更有上古蜃楼国废墟。

西洲（西荒+北荒旧地）：赤焰高原与归尘山脉。火山成群，灵玉与陨铁矿脉丰富，八荒大半法器在此铸造。归尘山脉之下镇压着九幽地脉。

中洲（独孤萱独镇三州后新抬之陆）：灵霄山脉所在，八荒灵脉最密集处，正道宗门林立，灵霄观为执牛耳者。天象常异，星轨偏移，催生了方家的星命瞳。

镜月裂隙：不属任何洲。镜月天旧址被从现实中剖离，悬于虚空裂隙。每月朔日在不同位置短暂现世。

外海：五洲之外的海域，龙族旁支、鲛人遗民散居，不涉洲内事务。
玩法：用于生成地图层级、旅行距离、地方势力和探索入口。
来源：chc/世界书.txt

## 主要势力总览 [lore_major_factions]
分类：factions
优先级：95
关键词：势力、宗门、世家
事实：灵霄观（中洲灵霄山脉主峰）：八荒第一拳修宗门，正道之首。镇守中洲灵脉与大量上古禁器。宗主巫雅萍。长女方瑶光（号照雪刀君），次女方璇玑（观星师），幼女方澜。

归尘书院（西洲归尘山脉）：八荒第一土修宗门，以有教无类闻名。院长独孤萱（号坤舆圣君），开山大弟子婉悦（号霜天剑首），末席弟子沈若棠，校医温青蘅。

赤焰文氏（西洲赤焰城）：八荒最古老修仙世家，以朱焰秘术独霸西洲三千年，掌握八荒大半法器炼制。家主文岳，独女文丽。

碧水宫（东洲碧水海域）：八荒第一水修宗门，统辖七十二岛。宫主清研，修沧海横流诀。

云来楼（各洲皆有分号）：楼主苏锦娘。三教九流出入之所，明面是客栈，实为八荒最大的信息集散地。

蜃楼城（东洲东海）：无统一管辖的自由港。逃犯、散修、情报贩子、黑市商人皆汇于此。码头区散修酒馆群最为知名。

镜月天（镜月裂隙）：已灭数千年的上古隐宗。镜心通明术可观他人神识如阅书卷。唯一幸存者胧是最后一位守阁人。

幻香宗（已灭）：魔道媚术宗门。洛媚出身处。覆灭后残党散入蜃楼城。
玩法：用于判断 NPC 所属势力、公开身份、资源调度和势力冲突。
来源：chc/世界书.txt

## 世界主要矛盾 [lore_core_conflicts]
分类：conflict
优先级：90
关键词：正道、禁术、某人
事实：其一，正道各宗互相制衡。灵霄观掌中洲灵脉，碧水宫控东洲海域，赤焰文氏握法器命脉，三方合作但长期互相提防。
其二，禁术扩散。上古禁术残篇与禁器胚体被重新发现、重构和转用，正在从封印器、炼器胚体转向活体控制、人格封印、权限网络和势力渗透。
其三，“某人”。这是一个代号，不是公开身份。其目标不是毁灭宗门，而是通过禁器网络和代理人控制关键节点；已知暗线涉及灵霄观、归尘书院、碧水宫、云来楼。
玩法：用于选择事件压力、反派计时、宗门暗斗和长期后果。

## 修炼境界 [lore_realms]
分类：realm-scale
优先级：100
关键词：境界、炼气、筑基、元婴、化神
事实：由低至高共七境，每境分初、中、后三期。境界越高，同境修士之间的实力差距越大——初期与巅峰之间可差出数倍战力，元婴以上尤甚，同一宗门同一境界的两位长老可能一方碾压另一方。

炼气期（十三层）：引天地灵气入体，冲刷经脉。凡人与修士的分水岭。
筑基期：经脉贯通，丹田初成。寿一百五十，可御器飞行。
结丹期：丹田凝结金丹，灵力外放。寿三百，可开宗立派。多数宗门长老、校医、散修老手处此境。
元婴期：碎丹成婴，元婴居于丹田。寿千年。一宗之主多为此境巅峰，战力已可独镇一方。
化神期：元婴与元神融合，神念外放，可操控天地灵气。当世顶尖，屈指可数。上古禁器多由此境修士所炼。
炼虚期（传说）：元神可离体遨游，寿近无限。上古时代终结后无人确证达到。
合体期以上（大乘/渡劫）：仅存于上古典籍残篇，蜃楼古国、锁星扣所属的上古炼器文明皆属此列。
玩法：用于战力、DC、NPC威胁、越境目标和成长结算。
来源：chc/世界书.txt

## 灵魂、肉体与元灵 [lore_soul_body_yuanying]

肉身、习惯、肌肉记忆和情绪条件反射会留下“原主印痕”。这些印痕可成为识破伪装、救援、反制或剧情裂缝。
玩法：用于解释禁术、复活、封印、残魂、法器承载和死亡边界。

# NPC人物设定_L0-L4分级
用途：告诉上下文规划器和人工整理者：哪些资料该放在哪一层，什么时候升级读取。

## L0 索引层
定义：身份、角色类型、所属势力、当前位置、短摘要、profileRef。用于快速知道“是谁”。
推荐位置：npc_registry / relation node
读取时机：任何NPC出场、场景挂载、战斗目标识别。

## L1 轻演绎层
定义：称呼、语气、动作锚、当前动机、可见信息。短对话和轻互动读到这里即可。
推荐位置：npc_profile_records.L1
读取时机：短对话、轻互动、临时任务、普通问询。

## L2 结构深层
定义：秘密、长期目标、关系、规则、弱点、反制入口、不能误写的边界。说服/威胁/欺骗/阵营影响需要读取。
推荐位置：npc_profile_records.L2
读取时机：说服/威胁/欺骗、关系变化、秘密试探、阵营影响。

## L3 全保真层
定义：完整角色来源、人物故事线素材、RAG长文、特殊私有规则。永久后果、高风险状态改变或全局后果裁决时读取。
推荐位置：npc_profile_records.L3
读取时机：永久后果、高风险状态改变、全局后果裁决、人物故事线素材、长RAG核对。

## L4 角色卡/世界包常驻锚
定义：跨聊天继承的世界尺度、世界枢纽、主角入口、全局反派和基础规则。L4不等于每轮塞进prompt，只表示资料应随角色包长期保留。
推荐位置：character scoped data / permanent world package
读取时机：角色包初始化、世界尺度、主角入口、全局反派和跨聊天继承。

## 本包角色分配建议

L4：
- 禁器网络/某人 [l4_forbidden_network]：跨洲反派压力、母器权限、符灰布点、铜雀台代理人行动的总锚点。；记录：目标库：organization_registry / npc_profile_records / special_item_registry；来源：chc/某人 与 RPG配置
- 碧水清研/李寻道家族线 [l4_bishui_family_line]：白手起家入口、水灵玉佩、清研异常和李飞轩旧事都从这里展开。；记录：目标库：主角入口模板 / npc_profile_records / item/special；来源：{{user}}主角卡、清研、李飞轩、RPG配置
- 灵霄方家线 [l4_lingxiao_family_line]：巫雅萍、方瑶光、方璇玑、方澜共同构成中洲核心压力；方澜视角时尤其应提升为L4。；记录：目标库：organization_registry / npc_profile_records / relationship_graph；来源：巫雅萍、方瑶光、方璇玑、方澜原始目录
- 八荒世界尺度 [l4_world_scale]：境界、法器、禁术、地图和奖励尺度是所有裁决的上限，不应塞进角色卡长文。；记录：world_lore_records; realm_registry; reference_texts

L3：
- 所有已有角色目录且有完整 profile 的核心NPC：清研、巫雅萍、方瑶光、方璇玑、方澜、独孤萱、婉悦、文丽、沈若棠、温青蘅、苏锦娘、李飞轩、胧、某人。
- L3 不代表每轮全读；只有高风险、永久变化、深度互动、状态切换、人物故事线推进或世界线后果时读取。

L2：
- 文岳、洛媚、恶童、碧水长老、云来楼代理人、任务堂执事等支线/线索/压力对象。
- 若连续互动、投入资源、结仇结盟、牵连禁器或成为反制入口，可晋升为L3。

L1：
- 任务堂执事、临时商贩、巡海弟子、黑市中介、药童、跑堂、船主、擂台对手等场景功能NPC。
- 必须有过期条件；没有后果就注销。

L0：
- 背景人群、无名弟子、围观者、一次性可感知对象。不编号，不写长期状态。

L4：跨聊天世界锚、主角入口、全局反派、量尺、基础世界法则。

## 境界与战力量尺 [ref_bahuang_realm_power]
分类：combat-scale
适用：combat、action_resolver、mechanics_registry、item_registry
字段：realmTier、phaseBonus、basePower、effectivePower、powerScore、threatScore、attackBonus、defenseBonus、energyPool
优先级：90
内容：境界不是胜负锁，只是灵压、感知、资源池和反制规模。越境可以成立，但必须收窄胜利目标或付代价。
境界阶梯与基础战力：炼气 tier=1 basePower=2 energyPool=6；筑基 tier=2 basePower=4 energyPool=10；结丹 tier=3 basePower=6 energyPool=16；元婴 tier=4 basePower=8 energyPool=24；化神 tier=5 basePower=10 energyPool=36；炼虚/传说 tier=6 basePower=12 energyPool=50。
小境界 phaseBonus：初期 +0，中期 +0.5，后期 +1，巅峰 +1.5。没有写明小境界时用 +0。
有效战力公式：effectivePower = basePower + phaseBonus + skillRank + itemPowerBonus + conditionBonus - injuryPenalty - pressurePenalty - pollutionPenalty。skillRank 0-6，itemPowerBonus 通常 floor(powerScore/3)，conditionBonus 总和上限 +3，伤势/压力/污染每到 3/5/6 档分别给 -1/-2/-3。
战力差比较：差 0-1 可正面胜负；差 2-3 低位只能靠克制/地形/法器争取局部胜利；差 4-5 低位只能逃脱、夺物、逼退、破招、拖延或伤分身；差 6+ 默认不能正面击杀，除非先通过任务削弱目标或使用禁器级代价。
战斗加值限幅：普通临时加成 +1，明确克制/准备 +2，核心法器或大师级技巧 +3/+4，传承级但有限制 +5/+6；超过 +6 必须有封印、冷却、污染、追踪、消耗或剧情债。

## 行动难度与骰子裁决量尺 [ref_bahuang_action_difficulty]
分类：resolution-scale
适用：dice、action_resolver、persuasion、environment、scene
字段：difficulty、dc、conditionBonus、thresholdGap、pressureDelta、successBand
优先级：85
内容：AI DND 有骰子与裁决工具，不沿用 SillyTavern 的纯无骰设计。低风险、已有明确条件的行动可以直接推进；结果不确定、代价较高或玩家要求公平裁决时，调用 dice/action_resolver 等工具。
建议 DC：8 日常；10 有压力；13 困难；16 险局；19 绝境；22+ 超纲。不要每个动作都掷骰，只有不确定行动才掷。
门槛差 thresholdGap = 当前可用数值 - 行动门槛。gap>=0 按 baseDC；gap=-1 时 DC +4 且必须付资源或留下代价；gap=-2 时只能做缩小目标，如短暂、局部、一次性、借外物；gap<=-3 不成立，除非先换目标或取得新资源。
技能/设定修正通常 -2 到 +6：无训练 -1/0，入门 +1，熟练 +2，精英 +3，核心功法/法器/专长 +4 到 +6。境界优势、地形、准备、克制、NPC协助、资源投入各可给 +1/+2，但总修正应受参考文本约束。
结果解释：高出 DC 5 以上为完全成功；达到 DC 为成功；低于 DC 1-4 为代价成功或局部成功；低于 DC 5 以上为失败并产生新局面。
失败仍应推进局势：消耗资源、增加关注、暴露风险、改变场景、给出新线索或转入战斗/谈判，不让玩家卡死。
